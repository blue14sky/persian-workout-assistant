# دستیار دیجیتال اجرای برنامه بدنسازی مربی

هدف پروژه، بررسی یک ابزار فارسی برای ورزشکاران بدنسازی است که از مربی برنامه می‌گیرند و می‌خواهند برنامه موجود را به چک‌لیست قابل‌ویرایش تبدیل کنند و اجرای ست‌ها را ثبت کنند.

## وضعیت پروژه
پروژه در مرحله اعتبارسنجی مسئله است؛ تقاضای کاربران، مزیت رقابتی، دقت استخراج و مدل درآمدی هنوز اثبات نشده‌اند. کدنویسی محصول شروع نشده است.

## تعریف فعلی
- **گروه تحقیق اولیه:** ورزشکاران بدنسازی که برنامه مربی را به شکل عکس یا فایل در گوشی نگه می‌دارند.
- **مسئله فرضی:** دسترسی به جزئیات برنامه و ثبت راحت اجرای ست‌ها ممکن است پراکنده یا وقت‌گیر باشد.
- **جریان پیشنهادی:** عکس واضح یا متن برنامه ← جدول قابل‌ویرایش ← تأیید کاربر ← ثبت ست‌ها و سابقه.
- **MVP آزمایشی:** ورود عکس واضح/متن، استخراج حرکت/ست/تکرار و اصلاح دستی، ثبت ساده تمرین.
- **خارج از محدوده فعلی:** تحلیل ویدئویی فرم، تشخیص آسیب، ساخت مستقل برنامه و پشتیبانی تضمینی از همه فرمت‌ها.
- **مزیت رقابتی:** هنوز فرضیه است؛ باید قابلیت رقبا را عملاً مقایسه کنیم و با کاربران آزمایش کنیم.

## مسیر بعدی
1. مصاحبه رفتاری با ورزشکاران گروه هدف
2. آزمون استخراج روی برنامه‌های واقعی و بی‌نام‌شده
3. آزمون نمونه ساده و سنجش استفاده مجدد
4. به‌روزرسانی کارت امتیاز با شواهد
5. فقط پس از اعتبارسنجی، تصمیم درباره نام، فناوری و ساخت MVP
