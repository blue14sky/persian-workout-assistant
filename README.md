# دستیار هوشمند تمرین ورزشی فارسی

هدف این پروژه، بررسی یک دستیار دیجیتال فارسی برای ورزشکاران بدنسازی است که برنامه فعلیِ دریافت‌شده از مربی را به جدول قابل‌ویرایش تبدیل کند و ثبت اجرای تمرین را آسان‌تر سازد. این گروه فقط نقطه شروع اعتبارسنجی است و هنوز تصمیمی درباره دامنه نهایی محصول گرفته نشده است.

## وضعیت پروژه

فعلاً در مرحله تعریف و اعتبارسنجی ایده هستیم. نیاز کاربران، تمایز نسبت به رقبا، امکان‌پذیری فنی و مدل درآمدی هنوز تأیید نشده‌اند؛ بنابراین در این مرحله کدنویسی محصول شروع نشده است.

## اصول فعلی

- گروه اولیه برای اعتبارسنجی: بدنسازانی که از مربی برنامه می‌گیرند؛ ترجیحاً برنامه‌ای که به‌شکل عکس در گوشی دارند.
- مسئله اولیه برای آزمون: دشواری احتمالیِ تبدیل برنامه مربی به قالبی که هنگام تمرین راحت بتوان از آن استفاده کرد و نتیجه ست‌ها را ثبت کرد.
- MVP آزمایشی محدود: ورود عکس واضح برنامه، استخراج حرکت/ست/تکرار به جدول قابل‌ویرایش، تأیید و اصلاح دستی، و ثبت ساده تمرین.
- PDF، اکسل، کتابخانه بزرگ آموزش حرکات و قابلیت‌های پیشرفته فعلاً اولویت ندارند؛ گسترش دامنه به نتیجه آزمایش‌ها وابسته است.
- اطلاعات استخراج‌شده باید پیش از استفاده توسط کاربر بازبینی و اصلاح شوند؛ دقت و مزیت نسبت به روش فعلی هنوز آزمایش نشده است.
- رقبای ایرانی و خارجی قابلیت‌های مشابهی در ثبت تمرین و برنامه‌سازی دارند؛ تمایز از مسیر ورود عکس برنامه مربی هنوز فرضیه است.
- محصول قرار است دستیار مربی باشد، نه جایگزین او.
- فرضیه‌ها تا زمان بررسی و آزمایش، واقعیت اثبات‌شده تلقی نمی‌شوند.
